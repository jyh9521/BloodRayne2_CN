# BIK 过场字幕：开场 6 句测试

适用于当前 v12 汉化。只覆盖 `video/A1S01P01_RU.srt`，不修改任何 POD、DLL、EXE、BIK 或配音。
安装脚本会核对 v12 的 LANGUAGE.POD、dinput8.dll 和 rayne2.exe。

## 手动测试

1. 退出游戏，双击本目录 `INSTALL.cmd`。现有俄语槽字幕会完整备份。
2. 自行启动游戏，仍选俄语语言入口，播放新游戏的第一段预录过场。
3. 约 4.8 秒应出现“准备好了吗？ 你今晚怎么这么安静？”。检查后面 5 句是否缺字、乱码、超出画面；英语配音应保持不变。
4. 回退只需退出游戏，再双击本目录 `ROLLBACK.cmd`。它恢复安装前的 SRT（包括用户之前的测试修改），不会撤销主体汉化。

`source/A1S01P01_ZH.utf8.srt` 是可编辑的中文源稿。`payload/video/A1S01P01_RU.srt` 是编译后的游戏文件。
**不要用文本编辑器把 payload 另存为 UTF-8/GBK；也不要将 source 文件直接复制进游戏。**
当前汉化使用自定义双字节字码对应位图字库，必须与字库映射同步编译。以后重新生成字库时也应一起重新生成 SRT。

## 本次覆盖与证据

- 开场 A1S01P01 的 6 句均译为中文；采用项目译名“塞弗林”“硫磺会”。
- 沿用用户现有 RU 文件的全部时间戳；该文件剩余外文内容为意大利语。本次译文核对随游戏附带的法语、意大利语字幕。
- 6 句全部使用现有 v12 字库已有的字，无须重建字库或更新代理 DLL。
- 本地共 15 部影片有外置字幕；本包仅为第一部影片的显示验证包，不代表其他影片已汉化。
- 检查了原始 SRT 读取函数、视频字幕布局调用以及最终位图绘制调用。
- 隔离的 x86 仿真执行原版读行与换行代码，覆盖 7 种分辨率、共 42 个用例；验证字节完整、字码未拆分、输出缓冲区未越界。
- 隔离目录完成安装和回滚测试；原文件按 SHA-256 逐字节恢复。
- 没有启动游戏，没有安装到真实游戏目录；实际字幕位置、音画同步及显示仍待用户确认。
