# 全量预录过场中文字幕（v13 视频增量包）

## 安装

保持当前 v12 主体汉化，可以保留已安装的开场字幕测试包，**不需要先运行旧版 RESTORE_PURE.cmd**。

1. 退出游戏。
2. 双击本目录 `INSTALL.cmd`，它会备份旧文件，再安装升级。
3. 自行启动游戏，仍选俄语语言入口，配音仍走英语资源。
4. 重点测试开场宴会的长句、回忆片段及后续视频；确认中文字幕、换行和声音正常。

本目录脚本默认放在游戏的 `_cn_project/releases/fmv-full-20260925` 下。
ZIP 按游戏根目录结构打包，解压到游戏根目录后再运行 INSTALL.cmd；不要只把脚本单独移到别处。

## 本次内容

- 15 部带外置字幕的剧情视频，共 222 条中文字幕。
- 修正开场句读，例如“是啊，今晚恐怕会有不少人死得很惨。”、“别担心，有我帮你呢。”。
- 按中文语义断句，清除沿袭外文的句间空格，不把所有句号一律替换为逗号。
- 人物、组织、武器和能力名称沿用项目名词表；附加术语见 `source/glossary.json`。
- 字库保留原有 1725 字的编号，追加 62 字；菜单、招式表、实时剧情文本和英文演职员表原始条目不变。
- 视频专用换行钩子按完整字码断行，并避免逗号、句号等出现在行首、左引号等出现在行尾；其他界面不走这个新钩子。

## 修改文件与 Mod 兼容

替换 `LANGUAGE.POD`、`dinput8.dll`，新增或替换 `video` 下的 15 个 `_RU.srt`。

**不改** `W32ART.POD`、`W32ENSND.POD`、磁盘上的 `rayne2.exe`、任何 `.bik` 视频、其他语言的 SRT 或配音资源。
`LANGUAGE.POD` 内只更新 `ART\GOTHICTITLE_RU.TEX` 字库贴图，其他 387 个条目与 v12 完全相同。
包含同名 DLL 或 LANGUAGE.POD 的其他补丁仍需另行合并；运行时钩子针对当前已核对的游戏 EXE。

## 回滚

退出游戏，双击本目录 `ROLLBACK.cmd`，恢复安装前的主体文件和字幕文件；原本不存在的 SRT 会移除。
备份保存在 `_cn_project/test_backup/fmv_full_20260925`。发现安装后另有手动修改时，会先停止，避免覆盖用户修改。

如需卸载全部汉化，先回滚这个视频增量包，再处理之前的开场测试包和 v12 主体；不要跳过增量包直接使用旧主体恢复脚本。

## 源稿与时间轴

`source/*_ZH.utf8.srt` 与 `source/subtitles_zh.json` 为可读中文源稿，游戏实际使用 `payload/video/*_RU.srt` 的自定义字码版本。
**不要将编译后的字幕另存为 UTF-8、GBK，也不要直接把 UTF-8 源稿复制进游戏。** 字库更新时必须同步编译字幕。

第一部影片保留用户已验证的时间轴；其他 14 部沿用游戏附带法语 SRT 的时间轴，并以法语为主要文本参考、意大利语等为辅助核对。原文件的部分时间重叠或过短提示列在 `timing_review.json`，尚待英语配音实机听测。

本包覆盖全部 15 部有外置字幕的剧情视频；`demo.bik`、`logos.bik`、`PROLOG.bik`、`ziggurat.bik` 没有配套字幕，本包未为它们新增文本，不等于已确认其中没有可翻译文字。

本次不启动游戏、不自动安装；离线测试与用户实机确认分开记录。开场显示路径已有用户截图确认，其余视频及本次长句换行仍待实机验证。
